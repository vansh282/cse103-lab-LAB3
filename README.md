# My First Repository

This project demonstrates Git version control.

## Project Overview
This repository is created as part of CSE103 Linux and Git Lab 3.

## Repository Structure
- README.md - Project documentation
- MARKDOWN_GUIDE.md - Markdown syntax examples
- lab3.txt - Lab practice file
- users.json - Public API user data

## Skills Demonstrated
- Linux commands
- Git and GitHub
- Markdown documentation
- Repository management
- Public API requests using curl
- JSON data analysis using jq

1. Clone the repository.
2. Open the project folder.
3. Read the documentation files.
